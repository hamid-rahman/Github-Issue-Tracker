
1️⃣ What is the difference between var, let, and const?
    Ans: var, let and const are used to declare variables in javascript
    var: var is a function scope. It can be redeclare or reassigned
    Let: let is a block scope. It can be reassigned but cannot redeclare in the same scope
    const: const is a also block scope. It cannot be reassigned or redeclare
